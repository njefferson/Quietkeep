The phases

0The groundin progress

A gate for third-person references, the historical backlog cleared, the a11y registry made self-deriving, this plan landed in the repo, and the research entries that later phases will be built on.

1The app can be enterednext

An imported store has a thousand actions and no contexts, roles, areas or goals — so the place filter admits everything, the horizon layer is empty and the offer is drawn from an undifferentiated wall. The machinery is built and has nothing to work with. This is what has stopped use every time.

2The horizon comes downnot started

A goal or an area gets a clock, so haven't moved on this in a while arrives as the same rising insistence everything else uses. No promote button, no screen to climb to.

3The situationnot started

Place is already done. The missing input is time — how long is available — and what is due today rather than what exists.

4The other directionnot started

What someone is waiting on from you, which the app has never modelled, and a screen for a person that shows both directions at once.

5The situated viewnot started

One surface with inputs, arrived at by answering the situation and never picked from a list of named screens.

6Coming backnot started

What moved since you were last here, cut at an anchor. A week away must not produce a wall.

7The menu and the unformednot started

Things that need shaping rather than doing, and a menu of what would actually help rather than what is owed.

8The whole thing, looked atnot started

Every surface rendered and read on an imported store, walked against all fourteen situations end to end.
